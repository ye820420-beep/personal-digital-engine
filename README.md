# 个人数字化引擎 · Personal Digital Engine

> **不是又一个记账 App，也不是又一个习惯打卡表。**
> 是一个文件——把它丢给任何一个 AI，它就变成你的个人数据系统。
>
> 你给它数据，它还你一套**只有你自己看得懂的账**。

---

## 为什么要有这个东西

你问 AI"我该怎么减肥""我该怎么赚钱""我该怎么学英语"，它永远只能给你**正确答案**。

不是因为它不行，是因为**它不认识你**。

它不知道你几点睡、一个月外卖花多少、连续几周没学完任何东西、上一个联系的人是谁。
不知道这些，它给出的建议就只能是正确的废话。

孙宇晨把它说得很直接：**"可视化、数据化、可总结化，然后全部搞成 Markdown 文档。"**
他自己的做法是：吃饭前后拍张照丢给 AI 算卡路里，睡眠数据交给 Oura Ring，每天让 AI 出一份日报。

问题在于——这套东西他说完了，**没有人把它做成一个你能直接用的东西**。

这个项目就是那个东西。

## 30 秒上手

1. 下载 [`skills/个人数字化引擎.md`](skills/个人数字化引擎.md)（**就这一个文件，不需要装任何软件**）
2. 打开豆包 / WorkBuddy / Claude / ChatGPT 任意一种，新建对话，**把这个文件丢进去**，说"装这个"
3. 说 **"跑一遍样例"** —— 60 秒后你会看到一整套成品长什么样
4. 觉得行，说 **"开始"** —— 它会分六组问你问题，答得再糙都行

之后每天随手丢一句进去就行：

```
"晚饭吃了牛肉面"       → 记一笔饮食
"打车 38"             → 记一笔支出
"今天 6 分"            → 记一笔情绪
"汇报又拖了"           → 记一笔工作
```

**一句"今天没运动"也是数据。** 系统能不能跑满两个月，取决于记录的成本有多低，不取决于你有多自律。

## ⭐ 一次部署，长期运行

**核心原则：文件即记忆。AI 的记忆不重要，文件才是记忆。**

所以换 AI、换电脑、换手机、开一百个新对话，系统都不会散——**只要文件在，状态就在**。

**换一个新 AI / 新设备时，粘这段开机语，30 秒恢复状态：**

```
你装了《个人数字化引擎》。先读 流水账-YYYY-MM.md 和 我的档案.md，
然后回我三行：本月记了多少条 / 断更了几天 / 今天该补记什么。
之后我说什么你就记什么，只回三行，别多说。
```

**每次对话结束，AI 会主动给你一个"接力块"**（日期 / 第几天 / 断更了哪几天 / 下次打开说什么 / 到期待办）。
复制走，粘进下一个 AI 或另一台设备，直接接着跑。

## 📱 手机上怎么用

**结论：能，但建议一个分工——手机负责"记"，电脑负责"看"。**

| 方案 | 怎么做 | 适合 |
|---|---|---|
| **A 同步盘 + 手机 AI App** | 数据文件夹放进坚果云/OneDrive/iCloud/微云，手机装同一个 App；记一笔时打开 AI App 传两个文件，说"记一笔：打车 38"，把更新后的流水账存回同步盘 | 想在手机上直接记的人 |
| **B 只丢素材（最轻）** | 饭照、截图、一句话丢进微信"文件传输助手"，回电脑一次性归档 | 想长期坚持的人（推荐 A+B 混用） |
| **C 手机上直接跑** | Android 用 Termux，iOS 用 iSH / a-Shell | 重度用户，门槛高，新手别碰 |

⚠️ 一个真实限制：手机 App 大多不支持"skill 目录"，所以**每次要重新上传那两个文件**（约 10 秒）。这是 App 生态的限制，不是这套系统的设计问题。

**看仪表盘**：`仪表盘.html` 传进手机用浏览器打开即可，已做手机适配（表格可横滑、卡片单列、页签记住位置）。

## 你会得到什么（全部是你自己电脑上的本地文件）

```
我的档案.md          六维档案 + 评分 + 三色状态灯
问题总表.md          按优先级排好的待修清单，每条的"第一步"小到今天能做
仪表盘.html    ★     双击打开，七个页签看懂自己
个人发展矩阵.md      现状 / 3 个月目标 / 达成信号 / 本周动作
流水账-YYYY-MM.md    所有原始数据，按月一个文件
日报-YYYY-MM-DD.md   每天的原始流水
日常琐事.md          待办 / 定期事务 / 随手想法
```

### 仪表盘的七个页签

| 页签 | 看什么 |
|---|---|
| **总览** | 综合分、六维雷达图、本月现金流、本周最要命的一件事、待修 TOP3 |
| **身体** | 体重曲线（带目标线）、睡眠时长（按达标度配色）、摄入 vs 消耗双曲线 |
| **情绪** | 每日评分折线（低分红点）、触发事件排行、哪种恢复方式真的有效 |
| **学习** | 每周投入柱状图、连续天数、在学清单卡在哪 |
| **工作** | 时间去向分布、可支配 vs 真正整块的时间、逾期项 |
| **关系** | 联系人列表（超过 30 天未联系标红）、本周互动、待修复的关系 |
| **财务** | 收支明细、分类占比、近 6 个月趋势、自动续费体检 |

## ⭐ 它跟别的仪表盘的分界线：每条建议都挂证据

别的工具告诉你"你超重了"。

本系统告诉你：

> **第 2 节第 9 条**：把家里的盐换成低钠盐
> 成本：一袋贵几块钱，口味几乎不变
> 收益：全因死亡风险降低约 12%（中国农村随机试验，20,995 人，跟踪 4.74 年）
> 证据等级：**A** ｜ 出处：NEJM 2021（DOI: 10.1056/NEJMoa2105675）
> ⚠️ **肾功能不全、正在服用保钾类药物的人，先问医生**

### 建议源是可以换、可以加的

这个功能的核心是 `skills/个人数字化引擎.md` 第 9 节的**建议源机制**——
当它需要给你一个"下一步动作"时，**先去 `references/` 里查，查不到才自己想办法，而且查不到必须明说**。

默认源：

> **《高性价比人生指南》** https://github.com/eternity4719/HowToLiveBetter
> 开源免费，CC BY 4.0，667 条建议，1,675 条原始文献链接。**本项目的建议源，非本项目作品，版权归原作者所有。**

**想加别的源，把 `.md` / `.txt` 丢进 `references/`，在登记表里加一行就生效：**

| 类型 | 例子 | 许可注意 |
|---|---|---|
| 开源书 | 《自学是门手艺》、OpenStax 教材（英文） | **CC BY-NC-ND 的只能原样引用，不许改写** |
| 官方文件 | 《中国居民膳食指南》 | 标注版本年份 |
| **你自己的文件** | 体检报告、报销制度、疫苗本、劳动合同、房贷合同、医嘱 | — |

**最有价值的是最后一类。** 开源书给的是通用答案，你自己的文件给的是只对你成立的答案——
**这才是"越用越贴合自己"的真正来源。**

完整规则见 [`references/建议源清单.md`](references/建议源清单.md)。

## 🔒 隐私：数据在哪，仓库里有什么

这是整个项目最需要说清楚的一件事。

**仓库里有什么**：只有规则、模板和样例数据。**规则是空的，它只是一份说明书。**

**你的数据在哪**：全程只在你自己的电脑上，就是那七个 `.md` 和 `.html` 文件。

**它会不会被传走**：不会。skill 第一条铁律写的就是"永不要求上传云端，永不把用户数据发往任何服务"。
本仓库还额外配了 `.gitignore`，就算你在自己的数据目录里 `git add .`，个人文件也一个都提交不上去。

**怎么彻底删除**：删掉那个文件夹。没有云端副本，没有账号，没有回收站之外的痕迹。

**换 AI 怎么办**：把整个文件夹复制走，丢给另一个 AI，它读同一套格式接着算。
这是选 Markdown 而不是选 App 的唯一理由——**数据不被任何一家锁住**。

详见 [`docs/隐私与数据主权.md`](docs/隐私与数据主权.md)。

## 三个使用原则

1. **别追求完美记录。** 三个月的糙数据，价值远高于一周的精确数据之后放弃。
2. **高优先级永远不超过 3 条。** 超过 3 条的结果是全部躺平。
3. **两个月之前不要下结论。** 这个系统的产出不是第一周的数字，是两个月后那份"AI 真的认识你了"的档案。
