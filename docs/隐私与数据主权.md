# 隐私与数据主权

这个文件不是免责声明，是**这个项目的核心设计**。

---

## 一句话

**仓库里只有规则，一条你的数据都没有。你的数据全程只在你自己的电脑上。**

---

## 具体怎么保证的

### 1. 仓库里放的是什么

只有三样东西：规则文件（`skills/个人数字化引擎.md`）、空模板、用**虚构人物"小林"**跑出来的样例产出。

规则文件本身是空的——它只是一份说明书，告诉 AI "收到数据以后怎么处理"。
它不包含任何人的人生信息，就像一本空白的记账本。

### 2. 你的数据存在哪

全部是**你自己目录下的本地文件**：

```
我的档案.md / 问题总表.md / 仪表盘.html / 个人发展矩阵.md
流水账-YYYY-MM.md / 日报-YYYY-MM-DD.md / 日常琐事.md
```

没有一个需要联网才能打开。断网状态下双击 `仪表盘.html`，一切照常。

### 3. 会不会被传走

skill 的第一条铁律写死了：**"永不要求上传云端，永不把用户数据发往任何服务。"**

需要说明的边界：**你是把数据发给豆包 / Claude 这类对话 AI 来处理它的**，所以那段对话内容会存在于该平台的聊天记录里。这是这类工具的天性，绕不开。区别在于：

- 传统 App：数据存在**它的**服务器上，你换一个 App 就得重新开始
- 本系统：处理过程在对话里发生，**结果以纯文本文件的形式落在你的硬盘上**，你可以随时把这些文件带到任何地方

如果你对某条数据极度敏感（身份证号、具体病史、银行账户），**用代号代替**（"卡 A""老毛病"）。系统要的是结构和趋势，不是精确原文。

### 4. 就算误操作也传不上去

仓库配了 `.gitignore`。就算你在数据目录里直接 `git add .`，下列文件也一个都提交不进去：

```
我的档案.md / 问题总表.md / 仪表盘.html / 日常琐事.md
流水账-*.md / 日报-*.md / *.local.md / references/ / .private/
```

这是双保险——**设计上数据就不该进仓库，技术上它也进不去。**

### 5. 怎么彻底删除

删掉那个文件夹。

没有云端副本，没有账号体系，没有"注销后 30 天内保留"。删完就真的没了。

### 6. 换 AI 怎么办

把整个文件夹复制走。装了这个 skill 的任何 AI 都能读同一套格式接着算，因为它读的是**文件**，不是某个平台的私有数据库。

这是选择 Markdown 而不是选择 App 的唯一理由。

---

## 给使用者的三条提醒

1. **不要在repo 的 issue 里粘贴你的真实数据。** 报告问题时贴结构、贴报错，不要贴内容。
2. **fork 之前看一眼**。这个项目鼓励 fork，但请确认你 fork 的目录下没有你自己的 `我的档案.md` 之类的文件。
3. **敏感内容用代号。** 系统需要的是"某一项偏高"这个事实，不需要知道具体是多少。

## 关于引用的第三方内容

本项目的"建议源"功能会读取《高性价比人生指南》
（https://github.com/eternity4719/HowToLiveBetter，CC BY 4.0，版权归原作者 eternity4719）。

- 本项目**不包含**该书的正文副本，只在使用时引用并标注出处
- 引用时会给出节次、条号、成本、收益量级、证据等级和原始 DOI，方便你自己去核
- 如果你本地放了该书副本，它会被放在 `references/` 目录，而这个目录已被 `.gitignore` 排除
