# 建议源清单（sources/）

> 这个目录决定了一件事：**AI 给你的建议是从哪来的。**
>
> 没有它，AI 给你的"下一步动作"是它自己编的——听起来都对，查不到出处。
> 有了它，每一条动作都必须挂上"谁说的、证据多硬、什么人不能做"。
>
> **用法**：把你认可的开源书 / 资料丢进这个目录（`.md` `.txt` 都行），AI 下次给建议时会自动先查这里。
> 目录里什么都没有也能跑，只是建议的出处栏会写"—"。

---

## 一、默认源（随仓库自带，开箱即用）

### 1. 《高性价比人生指南》HowToLiveBetter ⭐ 主力源

| 项目 | 内容 |
|---|---|
| 仓库 | `https://github.com/eternity4719/HowToLiveBetter` |
| 在线阅读 | `https://eternity4719.github.io/HowToLiveBetter/` |
| 许可 | **CC BY 4.0**（正文 book/ 与 docs/）｜工具代码 MIT |
| 规模 | 667 条建议（持续更新中，条目数会变，别锁死数字） |
| 每条格式 | 成本 / 说人话 / 收益 / 证据等级 / 来源 / 备注 |
| 证据分级 | **A** 荟萃分析或大型 RCT ｜ **B** 单项高质量研究或权威机构指南 ｜ **C** 观察性研究或专家共识 |
| 署名要求 | 转载需写明「高性价比人生指南」+ 仓库链接 + CC BY 4.0 链接；改过的要写明改过 |

**为什么拿它当主力源**：它是极少数把"成本"和"证据等级"同时标出来的中文资料。
别的资料告诉你"应该做什么"，它告诉你"花几块钱、换回 12%、证据 A 级、但肾功能不全的人不能做"。
最后那半句尤其重要——**愿意写"谁别做"的资料才是在算账，不是在劝你。**

**引用格式（必须给全六项，缺一项就不许写进依据栏）**：

```
《高性价比人生指南》第 2 节第 9 条 · 成本：一袋盐贵几元 · 收益：死亡风险约 −12% ·
证据等级 A · 出处 NEJM 2021（DOI 10.1056/NEJMoa2105675） ·
禁忌：肾功能不全、服用保钾类药物者先问医生
```

### 2. 《自学是门手艺》the-craft-of-selfteaching → 学习维度

| 项目 | 内容 |
|---|---|
| 仓库 | `https://github.com/selfteaching/the-craft-of-selfteaching` |
| 作者 | 李笑来 |
| 许可 | ⚠️ **CC BY-NC-ND** |
| 覆盖 | 自学方法论、刻意练习、如何把"学"变成"做出东西" |

⚠️ **ND（NoDerivatives）= 禁止演绎**。这条决定了用法：

- ✅ 可以：原样引用原句，注明出处和作者
- ❌ 不可以：改写、压缩、并入我们的模板、二次分发改编版
- **所以给建议时只能"引原文 + 说人话解释"，不许把它的内容当成自己的话重写一遍**

它最有用的一条方法论（原样引用）：

> 自学能力，对每个个体来说，是这个变化频率和变化幅度都在不断加大的时代里最具价值的能力。

## 三、最有价值的一类源：你自己的文件

`sources/` 不只放书。**任何你自己的资料放进来，AI 就变成按你的规则办事的人**：

| 丢进去什么 | AI 变成什么 |
|---|---|
| 体检报告 | 知道你哪些指标要盯着的记录员 |
| 公司报销制度 | 帮你判断这笔能不能报 |
| 疫苗本 | 到期提醒 |
| 劳动合同 | 加班/离职条款查询 |
| 你家房贷合同 | 提前还款划不划算的算账人 |
| 医嘱 | 严格按禁忌来，不给你想当然的建议 |

**这是"越用越贴合自己"的真正来源。**
开源书给的是通用答案，你自己的文件给的是只对你成立的答案。

## 五、三条不可越界（适用于所有源）

1. **查不到就写"—"。** 不许编条目号，不许把"我觉得有用"包装成某本书的原文
2. **健康类必须带具体禁忌人群**（"肾功能不全者先问医生"），不是"请遵医嘱"四个字
3. **ND 许可的源只能原样引用**，不许改写后当作本系统的建议输出
